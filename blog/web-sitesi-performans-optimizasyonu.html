Web Sitesi Performans Optimizasyonu: Core Web Vitals Rehberi

28 Temmuz 2026 5 dk okuma

Google'ın Core Web Vitals metrikleri, arama sıralamasını doğrudan etkileyen sayfa deneyimi sinyalleridir. Web sitesi performans optimizasyonu hem SEO hem de dönüşüm oranları için kritik öneme sahiptir.

Core Web Vitals Hedefleri

Metrik Açıklama Hedef
LCP Largest Contentful Paint — ana içeriğin yüklenme süresi < 2.5 saniye
INP Interaction to Next Paint — etkileşim yanıt süresi < 200 ms
CLS Cumulative Layout Shift — görsel kararlılık < 0.1

LCP İyileştirme Taktikleri

  • Hero görsellerini WebP/AVIF formatında sunun; responsive srcset kullanın
  • Kritik CSS'i inline edin, geri kalanını defer yükleyin
  • CDN ve edge caching ile sunucu yanıt süresini (TTFB) düşürün
  • Font-display: swap ile metin render gecikmesini önleyin

INP İyileştirme Taktikleri

  • JavaScript bundle boyutunu küçültün; code splitting uygulayın
  • Uzun görevleri (long tasks) parçalayın; Web Worker kullanın
  • Third-party script'leri (analytics, chat widget) lazy load edin

CLS İyileştirme Taktikleri

  • Görsellere width/height attribute'u ekleyin
  • Reklam ve embed alanları için sabit yükseklik ayırın
  • Web font yüklenirken fallback font ile layout shift'i minimize edin

Ölçüm Araçları

Google PageSpeed Insights, Chrome DevTools Performance paneli ve Search Console Core Web Vitals raporu düzenli takip için yeterlidir. Field data (gerçek kullanıcı verisi) lab data'dan önceliklidir.
